# BEETLE V1.3.5 Validation (software only)

- New user-supplied `simulator(2).html` layout retained as `simulator.html`, with the embedded native-equivalent engine updated.
- FX1, FX2, FX3 are independent: K1 selects row; K2 changes type; K3 value; OCT− removes only selected effect.
- Project format upgraded to V22 because FX2/3 slot identities must be stored explicitly. V21/V20/V19 input supported. V22 projects cannot be opened in V1.3.4.
- Fx pool capacity remains 48 total extra effect records per project.
- JieLi firmware app built for storage/OTA lab, OTA pilot and read-only diagnostics.
- App image and container structurally verified; V1.3.4 protected header and OTA loader preserved byte for byte.
- All 27 physical keyboard positions tested in browser for F3–G5, with contextual SEQ OP/mixer behavior.
- Host C, JS/Node, Chromium Playwright and firmware/installer checks: see tests/track/run_v135_regression.sh.
- No physical M-VAVE FM1 testing, real USB/DAW operation, firmware flashing or recovery validation. This is experimental firmware, not a safety certification.
