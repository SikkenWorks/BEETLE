# BEETLE V1.3.3 — USB Multitrack / Range Editing

**Release status: EXPERIMENTAL, source- and simulator-tested only. Not hardware-certified.**

## USB-C DAW recording

`HOME` → `PROJECTS` → `SETTINGS` → `USB MULTITRACK` → `ON`.

BEETLE's USB Audio Class 1 **input/capture device** then advertises **six discrete mono channels** (PCM16, 44,100 Hz):

| USB recording input | Source | Processing |
|---|---|---|
| Mono input 1 | CH1, synth | Channel volume, mute/solo, step-level DSP |
| Mono input 2 | CH2, synth | Same |
| Mono input 3 | CH3, synth | Same |
| Mono input 4 | CH4, synth | Same |
| Mono input 5 | CH5, synth | Same |
| Mono input 6 | CH6, drum kit | Drum gain, mute/solo, drum processing |

The six mono stems are **before global MASTER FX and Punch-In effects**. Therefore, per-lane pan is deliberately not encoded in these mono channels. Mix and pan them separately in your DAW. `USB MULTITRACK OFF` preserves the existing **two-channel stereo master**, including pan and MASTER/Punch-In effects. The stereo analogue output remains present in both modes, as does USB MIDI.

The setting **defaults to OFF every boot** and is **not saved** to V20 projects or flash. Changing it drops the USB connection and requests re-enumeration. In the DAW reopen/reselect the BEETLE recording device and choose mono inputs 1–6; operating system audio driver/DAW support for a 6-channel USB Audio Class 1 recording device is required and has not been tested here.

**Do not mistake the web simulator for hardware:** the WebSimulator Settings screen is a visual/control simulation only. Browsers cannot turn an ordinary USB device into an FM1 UAC audio peripheral.

## Tracker block operations

Stop playback and disarm REC. Hold **SEL** and rotate **K1** to select an inclusive range of steps on one channel. To assign an instrument across that selection, position **K2** on the **INST** cell and turn **K3**: only actual notes in the selection change instrument; empty and STOP rows remain untouched. A subsequent short press of **SEL** deletes every selected step, including associated FX and NOTE2 FX on CH6. Both operations are one Undo/Redo entry. To begin another selection, hold SEL and turn K1 again. The simulator additionally supports Shift+click row selection.

## Critical unverified issues

1. **No actual M-VAVE FM1 has been connected**: six-channel enumeration on Windows, macOS and Linux, DAW support, sustained full-speed EP4 delivery, CPU deadlines, SIE behaviour, memory contention and real recorded audio quality are **not proven**.
2. The six-channel USB stream is particularly demanding on the constrained FM1 real-time engine; absence of host-test errors does **not** guarantee glitch-free physical performance.
3. The storage-enabled firmware, OTA installation, flash ownership and recovery remain experimental. A failed update may make the FM1 unusable. Always maintain a **verified full-flash backup and independently working recovery path** before trying this experimental firmware. No web installer can guarantee rescue.
4. The control offers mode selection at runtime only; no persistent USB-mode setting is written across power cycles.
