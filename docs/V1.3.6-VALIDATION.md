# BEETLE V1.3.6 validation (software only)

- The author's revised `simulator(2).html` / V1.3.5 Workbench was kept as the UI base; only embedded firmware/simulator navigation logic and the displayed release version were updated.
- Workbench bug: the HOME/REC press bridge referenced a missing `WBH` variable, which threw a `ReferenceError`. The press-timing state is now initialized and tested.
- PROJECTS K1 scroll → SETTINGS SEL enter → SETTINGS SEL toggle ON/OFF → HOME return to PROJECTS was tested with real simulated pointer input (Chromium Playwright) as well as the public bridge.
- Native firmware routes the SETTINGS entry SEL press before generic tracker controls, consuming the event. SEL on SETTINGS toggles the USB Multitrack mode without leaving the page.
- Fixed V22 WebSimulator project decode using a mutable local FX type; verified save/load roundtrip.
- On-device HELP and simulator HELP clarify K1 menu, SEL enter, SEL toggle, and page navigation.
- Project format V22 and V19/V20/V21 migration support unchanged. Audio FX, instrument mapping, Song Chains, stereo/multitrack USB routing, sample format, and hardware input layout unchanged.
- Native JieLi storage/OTA-lab, OTA-pilot and read-only diagnostic builds passed; available app headroom remains positive.
- Firmware V1.3.6 structurally verified with unchanged protected header and OTA loader compared with V1.3.5. Embedded WebInstaller byte identity and SHA-256 checked.
- **Not tested on a physical M-VAVE FM1.** Firmware flashing and OTA recovery remain experimental. Verify a backup and a proven recovery process before installing.
