01 / SELECT FIRMWARE

LOCAL VERIFICATION

The browser accepts only the verified official V15 SHA-256. Files are not uploaded anywhere.

STORAGE NOTICE (V0.54): 12-project A/B persistent storage is experimental. Dense projects beyond 12KiB fail SAVE safely (no erase). The FIRST on-device storage initialization is DESTRUCTIVE: it erases all prior ETCH/Felucca user data in flash 0x97000–0xDFFFF, including ETCH projects and waveforms stored there. The firmware itself and OTA region are excluded. A complete, verified flash backup and recovery method are required BEFORE confirming SELECT + SAVE for 5 seconds on the device. No erase of unknown project data happens during a normal boot. Initial erase takes longer than the five-second confirmation hold: progress is shown on the FM1. Hardware storage operation is NOT verified on a physical FM1.
