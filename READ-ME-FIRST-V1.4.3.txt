BEETLE V1.4.3 STABILITY LAB — HARDWARE UNVERIFIED
================================================

Complete BEETLE source project, with all original V1.4.2 file paths
retained, including the build files, SDK integration, tests, web tools,
project manager, original assets, licenses and prior FWSC reference files.

Current firmware: BEETLE-V1.4.3-STABILITY-LAB-UNVERIFIED.fwsc
Current WebInstaller: WebInstaller.html (embeds identical firmware)
Hardware notes: docs/V143-STABILITY-MOUNTAINKING.md

UPDATES:
- All controls locked before project READ/WRITE progress screen and across
  the whole operation; unlock only after all buttons/notes have released
  and remained quiet for 320 ms.
- LCD redraw scheduling reacts to real measured audio pressure, without
  changing sequencer samples, polyphony, sample quality or audio clock.
- Skip inactive Step FX dispatch; PCM reference hashes unchanged.
- RC AUDIO LOAD displays the last Song Mode position when a real DMA
  deadline miss is detected on the FM1.

TESTS:
- Host MOUNTAINKING all 32 song positions using native C DSP,
  including position 19 with up to 8 synth and 4 drum voices.
- NUGGIE 12 oscillator types, two-loop playback tests.
- Two native JieLi target configurations built.
- Host 120-second max-voice DSP regression with UBSan.
- Embedded WebInstaller firmware SHA/CRC and package structure checked.

LIMITATIONS:
- No genuine on-device verification of the cracking fix or of a zero
  DMA DEADLINE outcome. Real hardware counters are needed.
- No independently verified recovery route. OTA is experimental.
- Browser simulator is a separate older frontend; does not emulate
  actual FM1 interrupt timing or USB hardware.
- Global 13-slot library remains PC-only.
- Encrypted MOUNTAINKING user fixture is in tests/private-fixtures:
  REMOVE it before publishing this repository publicly.
