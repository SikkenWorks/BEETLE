# BEETLE V1.3.4 — FX Slots, Storage and Compatibility Validation

**Build:** 20 October 2026. **Hardware status:** experimental; not independently tested on a physical M-VAVE FM1. Software-only checks do not prove USB enumeration, realtime audio stability, OTA recovery or safe flash ownership.

## Implementation

- **FX1 primary** remains stored in the existing native step field. **FX2 and FX3** are sparse, additional per-step records with independent FX types and effect amounts. They execute in order FX1 → FX2 → FX3 in the native synth engine.
- The global `TRACK_EXTRA_FX_CAP` is **48 supplemental FX entries for the entire project**, shared by all 48 patterns, channels and CH6 NOTE1/NOTE2 FX editors. FX1 does not consume the extra pool.
- The tracker FX cell shows `MUL` when more than one FX is active on that step. The FX editor shows `FX STORAGE x/48` and a temporary **FX STORAGE FULL** overlay on rejected insertion at capacity. Data is not overwritten on rejection.
- In the FX screen, **K2** selects the current synth FX slot; **OCT+** also advances FX1/FX2/FX3; **OCT−** removes the highlighted effect. **K1** selects TYPE or AMOUNT, **K3** changes the value. In the drum FX menu, **K2 switches NOTE1 and NOTE2**, and OCT+ is used for the FX slot.
- Clearing FX1 also clears its associated supplemental effects. The full-pattern and lane clipboard, block copy/paste/shift, and edit history include FX records; block-clear prunes orphaned FX. CH6's Note1 and Note2 source effects remain isolated.
- **TRK1 V21** serialization writes a bounded sparse FX slice within each pattern and preserves V19/V20 read support. V21 projects are not compatible with older firmware versions.

## Checks performed

- JieLi `pi32v2` native source compiles for storage-enabled OTA-lab + USB, OTA pilot + USB and read-only diagnostics. Compiled app reported **100,852 bytes** headroom in the storage+USB variant. Compilation is **not physical FM1 validation**.
- Host C regression: FX1+FX2+FX3, independent CH6 NOTE2, cap 48 and refusal of entry 49, V21 project save/load, removal, lane clipboard, block copy/paste/shift, Undo and orphan cleanup.
- Regression: V19 import, eight independent patches, all 64 Song Chains positions, Song Mode Punch-In recording, mono/chord levels, stereo panning, six isolated USB multitrack PCM buffers, selection editing, 12 oscillator types and five VA shapes, HELP chapter navigation, 120-second USB ring-buffer clock simulation.
- Browser: Chromium load and step FX control interaction without page errors; JavaScript syntax; V21 native encode/decode with three FX; original V19 native project decode.
- Firmware package: `.fwsc` decode, app audit, unmodified protected 16KiB flash header and OTA loader, correct app bytes, firmware product identity `FM-1_2119`, SHA-256 and exact WebInstaller embedded byte matching.

## Known limits / safety

1. The **48-record pool is project-wide**, not 48 per pattern. It stores FX2/FX3 only. Fully populated patterns may hit the pre-existing maximum project size (12,256 bytes) earlier. Oversized projects must be rejected before flash erase.
2. CH6 percussion DSP only applies the supported existing drum pitch and volume per-step FX to sample playback. Other FX choices may remain synth-specific.
3. The WebSimulator uses WebAudio, not bit-identical FM1 native DSP.
4. V20 and older firmware cannot read the new V21 format. Back up existing projects before saving them with V1.3.4.
5. Flash/update, hardware USB multitrack enumeration, long-running audio load and recovery from interrupted writes are **not yet proven on a physical FM1**. An independent recovery path and a verified full backup are necessary before installation.
