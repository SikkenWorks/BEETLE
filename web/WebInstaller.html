LOCAL VERIFICATION

INSTALL BEETLE RC1.0.7: Select NATIVE BEETLE FIRMWARE. The compiled FM1 package is embedded and checked by SHA-256, CRC and OTA-loader audit. For other compatible FM1 packages choose OTHER CUSTOM.

The package must contain a structurally valid UFW image, the exact preserved FM1 boot header, and the same byte-pinned BEETLE OTA loader. Other firmware formats require the separate UBOOT handoff below. No blind flashing.

No upload is required. The selected file must match the embedded BEETLE RC1.0.7 SHA-256. This safety check is never skipped.

Advanced Mode controls approved restore destinations only; it is no longer a gate for the SOURCE firmware. The target package SHA-256, protected header and OTA-loader checks remain mandatory.

Firmware is checked locally. The original BEETLE RC1.01 package is included in the ZIP. Stock V15 must be supplied separately and match the official pinned hash. Other custom packages remain disabled unless explicitly approved.

The browser accepts only the verified official V15 SHA-256. Files are not uploaded anywhere.

Storage and recovery details
BEETLE STORAGE POLICY: BEETLE uses 12 A/B-journalled project slots in 0x97000–0xDFFFF. This experimental storage variant can erase existing ETCH/Felucca user data during first-use initialization or an explicit WIPE ALL. Project Transfer V4 and the V18 format are supported. This installer does not back up flash. Once the vendor loader takes over, it controls firmware writing. Back up all data before installing, because a failed firmware update may require independent hardware recovery.

Read firmware safety warnings
Important: Package integrity and identified FM1 hardware cannot guarantee safe flashing. This installer cannot recover a device with an inaccessible bootloader or USB interface. A complete backup is required. Firmware Freedom routes must be independently tested. Do not disconnect during updates. The maintainer tests public BEETLE betas on real FM1 hardware.
Universal firmware switching / UBOOT
If a source firmware does not implement the compatible two-stage USB-MIDI OTA protocol, STOP and inspect the log. For ANY different loader or boot-image layout, BEETLE requests entry to the independent FM1 UBOOT mode. After reconnecting, use the target firmware's own compatible updater. This button does NOT write or approve the target firmware. Exact loader support and successful recovery depend on that firmware. You can also hold OCT- while switching on the FM1 if BEETLE is not responding. Back up projects before using any updater.

BEETLE REC recovery (when supported): start the FM1 holding REC (minimal USB mode without audio), then connect using desktop Chrome or Edge. If MIDI is not listed in Windows, try OCT- held at power-on for the independent UBOOT path. Connect directly with a USB data cable and close DAWs and other MIDI applications. Do not unplug during installation.

Technical installation notes

READ-ONLY DEVICE CHECK only sends identity queries; it does not start any update or write to flash. The identification FM-1_900 is shared; a successful handshake alone does not prove loader compatibility. A reboot between CHECK and FLASH is expected. If it reconnects to the old version instead of the OTA loader, the log records it. Save the log if an update fails.

A successful USB transfer is not enough. This installer reports success only after the FM1 restarts and returns the exact expected firmware identity.
