Firmware is verified locally. No upload to a server occurs. Stock V15 and ETCH V1.36/V1.37 are currently approved; Felucca and other custom releases need an exact audited firmware build.

The browser accepts only the verified official V15 SHA-256. Files are not uploaded anywhere.

Storage and recovery details
STORAGE NOTICE: 12-project A/B persistent storage is experimental. Dense projects beyond 12KiB fail SAVE safely (no erase). The FIRST on-device storage initialization is DESTRUCTIVE: it erases all prior ETCH/Felucca user data in flash 0x97000–0xDFFFF, including ETCH projects and waveforms stored there. The firmware itself and OTA region are excluded. A complete, verified flash backup and recovery method are required BEFORE confirming SELECT + SAVE for 5 seconds on the device. No erase of unknown project data happens during a normal boot. Initial erase takes longer than the five-second confirmation hold: progress is shown on the FM1. Storage initialization remains destructive; verify backup and recovery before approving.

Technical installation notes

READ-ONLY DEVICE CHECK only sends identity queries; it does not start any update or write to flash. A reboot between CHECK and FLASH is expected. If it reconnects to the old version instead of the OTA loader, the log records it. Save the log if an update fails.

A successful USB transfer is not enough. This installer reports success only after the FM1 restarts and returns the exact expected firmware identity.
