04 / FILE FORMAT AES-256-GCM · NO PASSWORD
AUTOMATIC .BEETLE ENCRYPTION

Projects download as encrypted binary .beetle files. They are unreadable in text editors and open automatically in the BEETLE Project Manager and V1.2 simulator. Each export uses a random nonce and an integrity tag. No password required.

The shared decryption key is bundled in BEETLE's public web tools. This prevents casual reading in Notepad, not determined extraction or secret storage. Older password-protected V1 backups can still be imported using their original password.
