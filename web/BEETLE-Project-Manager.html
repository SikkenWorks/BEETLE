04 / FILE FORMAT AES-256-GCM · NO PASSWORD
AUTOMATIC .BEETLE ENCRYPTION

Projects download as encrypted binary .beetle files. They are unreadable in text editors and open automatically in the BEETLE Project Manager and V1.2 simulator. Each export uses a random nonce and an integrity tag. No password required.

The shared decryption key is bundled in BEETLE's public web tools. This prevents casual reading in Notepad, not determined extraction or secret storage. Older password-protected V1 backups can still be imported using their original password.
05 / GLOBAL SAMPLE LIBRARY U01–U13 · GLOBAL FM1 SAMPLE LIBRARY
STORAGE STATUS: This portable PC-side sample library is independent of any .beetle project and can be synchronized to migrated BEETLE Storage V2. It supports full WAV files, replacement and deletion. FM1 device-global transfer: requires a migrated Storage V2 volume and BEETLE V1.4.22 sample transfer firmware. Samples in this library remain separate from the device until explicitly synchronized. This tool validates PCM/float WAV structure, preserves the original bytes, and lets you export individual WAVs. WAV is converted to 22.05 kHz mono 4-bit BD4S for device transfer; the original WAV stays unchanged on your computer. U01–U13 are shared across all twelve projects once synchronized to a Storage V2-equipped FM1. On-device playback remains hardware-unverified. Save a .beetlebank backup before closing this page.
